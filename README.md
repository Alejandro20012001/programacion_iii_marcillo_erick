🚀 Programación III - Guía y Repositorio de Código

Bienvenido al repositorio oficial de la materia Programación III. Este espacio está destinado a almacenar los ejercicios, prácticas y proyectos desarrollados durante el semestre, abarcando desde las bases del desarrollo web hasta el diseño de aplicaciones fullstack modernas.

📚 Módulos y Conceptos Clave

1. HTML5 (HyperText Markup Language)

¿Qué es?: El lenguaje de marcado estándar utilizado para estructurar y dar significado al contenido de una página web.

Conceptos clave:

Etiquetas Semánticas: <header>, <nav>, <main>, <article>, <footer> para estructurar el contenido accesibles y SEO-friendly.

Formularios e Inputs: Captura de datos con validaciones nativas.

DOM (Document Object Model): Estructura de árbol que representa los elementos HTML en memoria para ser manipulados mediante código.

2. JavaScript (ES6+)

¿Qué es?: El lenguaje de programación dinámico e interpretado que añade interactividad y lógica a las páginas web.

Conceptos clave:

Variables y Scope: Declaración con let y const (evitando var).

Funciones Flecha (=>): Sintaxis concisa para declarar funciones implícitas y conservar el contexto.

Asincronía (Promises y async/await): Manejo de peticiones a APIs sin bloquear el hilo principal de ejecución.

Métodos de Arreglos: Manipulación funcional de datos con .map(), .filter(), .reduce(), etc.

3. TypeScript

¿Qué es?: Un superset de JavaScript desarrollado por Microsoft que añade tipado estático y comprobación de errores en tiempo de compilación.

Conceptos clave:

Tipos Básicos e Interfaces: Definición estricta de la forma que deben tener los objetos y variables (interface User { id: number; name: string; }).

Generics: Creación de componentes y funciones reutilizables que funcionan con múltiples tipos de datos.

Compilación (tsc): Transpila el código TypeScript a JavaScript válido para su ejecución en Node.js o el navegador.

4. NestJS

¿Qué es?: Un framework de Node.js progresivo construido con TypeScript para desarrollar aplicaciones del lado del servidor (Backend) eficientes, escalables y estructuradas.

Conceptos clave:

Módulos, Controladores y Servicios: Arquitectura organizada basada en Inyección de Dependencias.

Decoradores (@Controller(), @Get(), @Post()): Anotaciones que definen metadatos sobre clases y rutas HTTP.

DTOs (Data Transfer Objects): Modelos para estructurar y validar los datos que entran en la API.

5. ReactJS

¿Qué es?: Una librería de JavaScript desarrollada por Meta enfocada en la creación de interfaces de usuario (Frontend) dinámicas y basadas en componentes.

Conceptos clave:

JSX: Extensión de la sintaxis de JavaScript que permite escribir estructuras similares a HTML dentro del código de JS.

Componentes: Bloques de construcción independientes y reutilizables.

Hooks (useState, useEffect): Funciones especiales para gestionar el estado del componente y sus ciclos de vida.

Props: Parámetros pasados de un componente padre a un componente hijo.
